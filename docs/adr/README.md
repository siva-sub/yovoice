## 背景数字

整卷实测数据来自 2026-10 的 Shadow Slave 第六卷流程（`ss_audiobook/`）：

- 170 章、8,970 条记录（叙述 7,085 / 对白 1,390 / 心声 495）、18 个说话人
- 单章台词 52 条（中位）、最大 95 条；单章正文最大 11,301 字符
- 置信度低于 0.5 的待复核条目 367 条
- 已渲染 1,317 分钟（约 22 小时）音频，8,794 次请求
- 音效 cue 273 条（hit 191 / bed 81 / mute 1），环境层 14 段覆盖全部 170 章
