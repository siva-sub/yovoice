## 界面与特性的归属

界面共六个入口，其余特性挂在它们下面：

| 界面 | ADR | 覆盖的特性 |
| --- | --- | --- |
| **书架（系列 / 卷）** | 0012、0014 | 书级进度矩阵、系列复用、跨书队列与配额、共享资产引用计数、归档 |
| **归因阅读与改派** | 0007 | 键盘复核、两人对话翻转探测、章节差异、提词器试听 |
| **角色与 cast 管理** | 0008 | 锚点候选对比、别名与亲属图、未知专名清单、漂移监控 |
| **音频库** | 0009 | 逐行 take 历史、种子账本、LUFS 归一、导出预设（试听包 / m4b） |
| **渲染面板** | 0010 | 成本预估与预算闸门、缓存命中、可续跑清单、热车道保活、分车道队列 |
| **验收（QA）** | 0013 | 渲染回读 WER 闸门、逐章响度、空洞与削波、校对式通听 |

## 背景数字

整卷实测数据来自 2026-10 的 Shadow Slave 第六卷流程（`ss_audiobook/`）：

- 170 章、8,970 条记录（叙述 7,085 / 对白 1,390 / 心声 495）、18 个说话人
- 单章台词中位 52 条、最大 95 条；单章正文最大 11,301 字符（超过前端 11,000 上限，需拆段）
- 置信度低于 0.5 的待复核条目 367 条（4%）
- 已渲染 1,317 分钟（约 22 小时）音频，8,794 次请求
- 音效 cue 273 条（hit 191 / bed 81 / mute 1），环境层 14 段覆盖全部 170 章
- 锚点 21 条实测：通过 17（11 条带提示），未通过 4（浊音比 0.21–0.55，听感是气声）
